Win SMB with speed, clarity, and one story

In SMB you rarely need heavy enterprise theater. You need to find the owner-pain fast, show relief in 20 minutes, and make the next step stupidly easy.

SMB golden rule: replace chaos (Excel + WhatsApp + accountant back-and-forth), not “transform HR strategy.” Sell time back + fewer errors + one place.

1. SMB vs Enterprise (how you sell changes)

SMB (you)

What matters

  • Cycle: days/weeks, not months
  • 1–3 people decide
  • Owner / office manager / HR generalist
  • Price + time-to-go-live
  • Enemy #1: Excel + “we’ll manage somehow”
  • Demo must feel immediate
Enterprise (less often)

Different game

  • MEDDPICC + security + procurement
  • Many stakeholders
  • Pilot committees
  • Paper process can kill deals

Keep the enterprise playbook for later upmarket deals. Don’t over-process SMB.

2. Who you actually talk to

Name the persona. Pitch to their week, not to “HR transformation.”

Owner / Founder

Cares about

Cost, control, not hiring an HR team, sleeping better at month-end.

“You shouldn’t need 4 tools and a Friday nights spreadsheet to know who worked, who’s off, and what to pay.”
Office / People Ops

Cares about

Chasing documents, timesheets, leave requests, onboarding chaos.

“Your job becomes approvals and exceptions — not detective work on WhatsApp.”
Accountant / Finance

Cares about

Clean variables, fewer corrections, payslips distributed, expense mess.

“Time + expenses land ready for payroll — lock the cycle so last-minute edits stop.”
Manager (influencer)

Cares about

Approve leave, see who’s in, stop babysitting clock-ins.

3. Qualify in 5 minutes (SMB MEDDIC-lite)

Don’t run full MEDDPICC on a 40-person company. Use this light checklist.

  • Pain now? Something hurts this month (payroll errors, inspector fear, growth hiring, forgotten leave).
  • Owner reachable? Can you get the person who pays in call 1 or 2?
  • Team size fit? Usually ~15–200 (confirm your Factorial sweet spot for your market).
  • Current stack? Excel / local payroll only / old HRIS / multi-tools.
  • Timeline? “This quarter” beats “exploring someday.”
  • Budget signal? Already paying 2–3 tools or an admin salary for chaos.

If no pain + no owner + no date → nurture. Don’t run full demos for tourists.

4. SPIN questions for SMB (short)

Situation
How do people request holidays today?
Where does clock-in live — app, paper, memory?
Who prepares payroll variables for the accountant?
Problem
What breaks every month-end?
What still needs chasing on WhatsApp?
When someone joins, how many days until laptop + contract + access are done?
Implication
If timesheets are late, what happens to payroll mistakes and trust?
If you hire 10 more people this year, does the current process survive?
Need-payoff
If leave + time + documents were in one place, how many hours/week come back?
What would “employees self-serve” change for you personally?

5. SMB bundles (keep it simple)

Don’t open the whole catalog on call 1. Offer a clear land package.

Land #1 · Most common SMB

Core + Time Off + Time Tracking

Pitch: “Stop the holiday/time chaos and feed cleaner data to payroll.”

Add Shifts only if they have rotating workforce (retail, clinics, hospitality).

Land #2 · Hiring pain

Core + Recruitment (+ Onboarding workflows)

Pitch: “From career page to signed contract without email archaeology.”

Expand #1

+ Expenses (and Cards if relevant)

After land: “Receipts on phone → approval → payroll.”

Expand #2

+ Performance / Engagement

When they’re past firefighting: reviews + eNPS without new tools.

Bundling phrase (use this)

“Let’s start with the weekly pain — time and absences on Core — then plug expenses when month-end is calm. Expanding is easy because it’s the same employee.”

6. The 20-minute SMB demo (with People Path)

For SMB, never demo everything. Show 4 beats max.

  1. 2 min · Mirror their pain — “You said month-end timesheets + leave chasing. I’ll show only that path.”
  2. 12 min · Click People Path — Welcome (Start onboarding) → Rhythm (Clock in / PTO) → Money (Scan receipt / Lock payroll) if finance cares.
  3. 3 min · Contrast — “Today: WhatsApp + Excel. Tomorrow: one spine.”
  4. 3 min · Clear next step — trial / second call with owner / proposal date.

Default SMB click path

1) Start onboarding 2) Clock in + request Friday off 3) Scan receipt → approve → lock payroll (Skip Culture/IT unless they asked.)

7. Classic SMB objections

“We’re too small”

“That’s exactly when bad process hurts most — one admin wearing five hats. Factorial Core is built so you don’t hire a full HR stack to get organized.”

“We already use Excel / WhatsApp”

“It works until it doesn’t — leave fights, missing punches, payroll corrections. Want to see one employee week without chasing?”

“Other tool is cheaper”

“Cheaper per seat can be expensive in hours. What are you paying in tools + admin time + payroll fixes today? Let’s compare that, not only list price.”

“We need to think”

“Totally. What specifically are we thinking about — price, go-live effort, or whether the owner has seen it? Let’s book that exact conversation.”

“Our accountant already has something”

“Perfect — Factorial prepares cleaner variables and collaborates with payroll partners. Accountant keeps their role; you stop sending messy inputs.”

“Implementation scares us”

“SMB rollout is phased: directory + absences + time first. We don’t boil the ocean on week one.”

8. Closing SMB (simple mutual plan)

End every good call with 3 things

  1. Confirmed pain in their words
  2. Recommended land bundle (usually Core + Time Off + Time Tracking)
  3. Dated next step — owner demo, trial kickoff, or proposal review
“Next step I’d suggest: 25 minutes Thursday with you + [owner], same story focused on month-end. If it clicks, we scope a go-live date the same week. Does Thursday 10:00 work?”

9. Your weekly SMB seller habit

  • Mon: Pick top 10 deals — kill “no date / no pain” ones
  • Daily: Run the 4-beat People Path once out loud (2 minutes)
  • Every call: 4 SPIN questions before any clicking
  • Every proposal: one land bundle + one expand path (not 12 modules)
  • Fri: Note top 3 objections you heard — sharpen answers

Before you dial (60 seconds)

1) Pain hypothesis? 2) Persona (owner / ops / finance)? 3) Land bundle? 4) Which 3 clicks will I show? 5) What dated ask will I make?
